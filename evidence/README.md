# Lab 01 — Evidence checklist

Save only sanitized evidence from the fictional lab data.

- [ ] `01-initial-validation.png` — initial script output showing findings.
- [ ] `02-clean-validation.png` — output after all mock data issues are resolved.
- [ ] `03-iam-flow.png` — simple flow diagram: HR/source → IAM validation/approval → directory or target application.
- [ ] `04-investigation-notes.md` — explain two findings, evidence to verify, who approves a change, and the audit record to retain.
- [ ] `05-entra-observations.md` — optional notes on where users, groups, enterprise apps, audit logs, sign-in logs, and provisioning logs appear in a personal lab tenant.

Never commit real user data, tokens, passwords, client secrets, private keys, confidential screenshots, or employer records.
